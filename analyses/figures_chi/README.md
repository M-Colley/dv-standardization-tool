# OpenDV-HCI — CHI figure set

Generated by [`opendv/analysis/make_chi_figures.py`](../../opendv/analysis/make_chi_figures.py) from the
39-study run of `sources_manifest_no4tu.yaml` (2026-11-06). Every number in the figure
captions is computed from the run artifacts.

**Pipeline that produced the inputs** (commands in `docs/reproducibility.md`)

1. `opendv batch --manifest sources_manifest_no4tu.yaml --snapshot-manifest --cache-dir data/processed/cache`
   - all 39 development studies: 11 fetched from their repositories, 28 pinned downloads in `data/raw/development/`;
   - local-LLM fallback after header matching, with the plausibility check (rules v1.3) and the `definition` shortlist;
   - model: `google/gemma-4-E2B-it`, the largest default model that fits the 16 GB GPU used.
2. `opendv analyze --input-dir <run>/standardized --output-dir analyses/output_python_full --exclude-llm-deduced`
3. `python -m opendv.analysis.multiverse_analysis --input-dir <run>/standardized` → `analyses/output_multiverse/`
4. `python -m opendv.analysis.make_chi_figures` → this folder (vector **PDF** + 300-dpi **PNG** per figure)

## Figures & suggested captions

- **`fig0_teaser`** — 2×2 overview combining (a)–(d) for the paper's first page.
- **`fig1_pipeline`** — *From an open catalog to comparable evidence.* Corpus
  attrition through the pipeline: 39 sources, 134 canonical DVs, 95 poolable
  DVs, of which 66 are pooled across ≥ 3 studies.
- **`fig2_presence_matrix`** — *Dependent-variable coverage across 39 open HCI
  datasets.* Cells mark a canonical DV present in a dataset, colored by
  thematic cluster. Marginals show per-DV study count and per-dataset DV
  count. Mean pairwise overlap is only Jaccard = 0.085. The figure's height
  was set for 11 studies; at 39 the row labels overlap.
- **`fig3_overlap_heatmap`** — *Pairwise DV-vocabulary overlap (Jaccard).*
- **`fig4_forest_mental_demand`** — *Evidence synthesis unlocked by
  standardization.* Random-effects forest plot for NASA-TLX Mental Demand
  across 21 datasets whose raw labels differed. Both the Wald and the
  Hartung-Knapp-Sidik-Jonkman intervals are shown. I² = 99.9% means a shared
  canonical name does not guarantee scale or population comparability. The
  first row (SenseCobot, 17.5% of the weight) is an LLM error, see caveat 1.
- **`fig5_causal_dag`** — *Within-study causal structure among standardized
  DVs.* DirectLiNGAM on z-scores. The only rows complete on the largest
  co-observed DV set all come from Running into Traffic, so this is **not** a
  cross-study DAG. Edge stability: `output_python_full/causal_bootstrap_stability.csv`.
- **`fig6_mapping_coverage`** — *Schema coverage by dataset.*

## Methods caveats (read before using the figures)

1. **LLM-deduced mappings are provisional.** In the leave-alias-out benchmark
   the LLM gives the curated DV for 41% of the DV columns of the first 23
   studies and 17% of the 16 added ones (`analyses/output_llm_evaluation/`).
   82 of the 95 pooled DVs include LLM-deduced rows (`includes_llm_deduced`
   in `meta_analysis_summary.csv`). Example: the LLM maps SenseCobot's EEG
   beta/alpha-ratio statistics to mental demand; their values pass the range
   check, and the study mean (0.39 of 20) takes 17.5% of the weight in
   Fig. 4. All study × DV rows with `mapping_source = llm_deduced` are listed
   in `harmonized_dv_summary.csv`. For claims, prefer the `*_llm_excluded`
   files (49 meta-analyzable DVs, 36 with k ≥ 3). Fig. 2, Fig. 3 and the PCA
   composite use all mappings.
2. **Observation-level n.** Meta-analysis weights use row counts, not
   participants, so large row-level exports (TLX formats with 3,888 rows,
   FACT-AV with 2,600) weigh heavily. The participant-level alternative is one axis of the multiverse
   (`analyses/output_multiverse/`).
3. **Scale harmonization decides many estimates.** Six of the added studies
   record the NASA-TLX on 0–100. Pooled on their raw scales the subscales
   move from 6–8 to 13–23 on the schema's 0–20; `perceived_safety` ranges from 0.85 to
   3.70 and `understanding_rating` from 3.51 to 7.64 depending on this one
   choice.
4. **Small k.** Many pooled DVs have k = 2–3. Use the HKSJ interval
   (`hksj_ci95_low/high`) rather than the Wald interval for inference.
5. **Measurement invariance.** No shared scale reaches even configural
   invariance: SUS, both Van der Laan scales, perceived safety and both
   UEQ-S scales misfit, and the NASA-TLX model cannot be fitted because one
   study's physical demand has no variance (column `measurement_invariance`
   in `meta_analysis_summary.csv`; `measurement_invariance.csv`). Treat
   pooled means, including Fig. 4's Mental Demand, as describing where
   studies sit rather than as comparable measurements; `docs/cross_study_insights.md`
   pools correlations instead.
6. **Changes relative to the 11-study figure set of 2026-10-25.** 28 studies
   added (2026-11-04 and 2026-11-05); plausibility rules v1.3 and header
   matching; perceived safety scored from its items; Van der Laan keying of
   ROADS and eHMI-for-All fixed; the scale detection no longer reads
   off-range scales as 0–20. See `docs/changelog.md`.
