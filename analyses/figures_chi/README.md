# OpenDV-HCI — CHI figure set

Generated by [`opendv/analysis/make_chi_figures.py`](../make_chi_figures.py) from the
11-study run of `sources_manifest_no4tu.yaml`. Every number in the figure
captions is computed from the run artifacts.

**Pipeline that produced the inputs (2026-10-25)**

1. `python -m opendv.run_batch_standardization --manifest sources_manifest_no4tu.yaml --output-dir data/processed/catalog_meta_analysis --snapshot-manifest --workers 8`
   - batch download and standardization of all 11 sources;
   - local-LLM fallback with the plausibility check (rules v1.1) and definition-aware candidate retrieval;
   - model: `google/gemma-4-E2B-it`, the largest default model that fits the 16 GB GPU used.
2. `python -m opendv.analysis.multi_study_analysis --input-dir data/processed/catalog_meta_analysis/standardized --output-dir analyses/output_python_full --exclude-llm-deduced`
3. `python -m opendv.analysis.multiverse_analysis --input-dir data/processed/catalog_meta_analysis/standardized` → `analyses/output_multiverse/`
4. `python -m opendv.analysis.make_chi_figures` → this folder (vector **PDF** + 300-dpi **PNG** per figure)
5. `python -m opendv.analysis.evaluate_llm_mapping …` → `analyses/output_llm_evaluation/` (LLM mapping accuracy, see below)

## Figures & suggested captions

- **`fig0_teaser`** — 2×2 overview combining (a)–(d) for the paper's first page.
- **`fig1_pipeline`** — *From an open catalog to comparable evidence.* Corpus
  attrition through the pipeline: 11 sources, 90 canonical DVs, 54 poolable
  DVs, of which 12 are pooled across ≥ 3 studies.
- **`fig2_presence_matrix`** — *Dependent-variable coverage across 11 open HCI
  datasets.* Cells mark a canonical DV present in a dataset, colored by
  thematic cluster. Marginals show per-DV study count and per-dataset DV
  count. Mean pairwise overlap is only Jaccard = 0.098; 12 DVs are shared by
  more than two studies.
- **`fig3_overlap_heatmap`** — *Pairwise DV-vocabulary overlap (Jaccard).*
- **`fig4_forest_mental_demand`** — *Evidence synthesis unlocked by
  standardization.* Random-effects forest plot for NASA-TLX Mental Demand
  across seven datasets whose raw labels differed. Both the Wald and the
  Hartung-Knapp-Sidik-Jonkman intervals are shown. I² = 99.7% means a shared
  canonical name does not guarantee scale or population comparability.
- **`fig5_causal_dag`** — *Within-study causal structure among standardized
  DVs.* DirectLiNGAM on z-scores. The only rows complete on the largest
  co-observed DV set all come from FACT-AV, so this is **not** a cross-study
  DAG. Edge stability: `output_python_full/causal_bootstrap_stability.csv`.

## Methods caveats (read before using the figures)

1. **LLM-deduced mappings are provisional.** With rules v1.1 and definition
   retrieval, 59% (52/88) of accepted LLM DV mappings are correct on held-out
   real columns (`analyses/output_llm_evaluation/`). Several pooled
   DVs include LLM-deduced rows (`includes_llm_deduced` in
   `meta_analysis_summary.csv`). Examples: `AOA1` (k = 3) includes the
   Road-Bumps touch columns `Acc` and `PeakValue`, and `sts_ad_trust` (k = 3)
   rests on LLM mappings of FACT-AV / 3D-Display columns such as
   `drivingstyle` and `complex`. All study × DV rows with
   `mapping_source = llm_deduced` are listed in `harmonized_dv_summary.csv`. For claims, prefer the `*_llm_excluded` files,
   which keep 34 meta-analyzable DVs (6 with k ≥ 3). Fig. 2, Fig. 3 and the
   PCA composite use all mappings.
2. **Observation-level n.** Meta-analysis weights use row counts, not
   participants, so the large raw exports (FACT-AV, eHMI-Opt) dominate. The
   participant-level alternative is one axis of the multiverse
   (`analyses/output_multiverse/`). Several LLM-touched estimates are fragile
   across specifications: `perceived_safety` ranges from −0.24 to 4.27, and
   `understanding_rating` from 3.33 to 7.56 depending on scale harmonization.
3. **Small k.** Most pooled DVs have k = 2–3. Use the HKSJ interval
   (`hksj_ci95_low/high`) rather than the Wald interval for inference.
4. **Measurement invariance.** Of the four scales whose items are available
   in two studies, only Van der Laan *satisfying* reaches scalar invariance,
   the level needed to compare means. SUS and NASA-TLX fail already at the
   configural level, and Van der Laan *usefulness* reaches only metric
   invariance (column `measurement_invariance` in
   `meta_analysis_summary.csv`; `measurement_invariance.csv`). Treat pooled
   means of those scales, including Fig. 4's Mental Demand, as describing
   where studies sit rather than as comparable measurements.
5. **Changes relative to the June 2026 figure set.** Trim-and-fill now
   matches `metafor`. The PCA composite drops rows with no shared DV
   observed. LimeSurvey `neg1`/`neg2` AOA answers are recoded instead of
   dropped. Psych-Conflict's text Likert labels are recoded, and that study
   now contributes 15 DVs. OSF-cwd6h is included. Item → scale edges are
   excluded from the DAG. See `docs/changelog.md` and
   `docs/research_agenda.md`.
